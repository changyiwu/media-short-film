# 換角重製：類型規則

> 本類型的片放在 `output/換角重製/<片名>/`。這裡只放**這個類型**的規則；所有片共用的規則在上一層 `../AGENTS.md`，兩份都要讀。
> Claude Code 讀本資料夾的檔案時，會透過同資料夾的 `CLAUDE.md`（`@AGENTS.md`）自動載入本檔。

## 這類片是什麼

照參考影片換主角：動作（骨架）、背景、聲音沿用原片，只換人或換台詞裡的詞。

## 規則

- 做法照 `../../docs/08_換角重製.md`：片子資料夾寫 `recast.json`，在片子資料夾跑 `python ../../../tools/recast.py <子命令>`；不走 `make_film.py` 的 h3 階段（它不會把 `control` 傳給 H3）。
- 參考影片與裡面的人聲是別人的作品：沒取得授權不要公開，發布前先看該片 `發布資訊.md` 的〈授權提醒〉。仿原聲的參考音只放片子資料夾的 `素材/`。
