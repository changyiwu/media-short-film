# 錄音室：類型規則

> 本類型的片放在 `output/錄音室/<片名>/`。這裡只放**這個類型**的規則；所有片共用的規則在上一層 `../AGENTS.md`，兩份都要讀。
> Claude Code 讀本資料夾的檔案時，會透過同資料夾的 `CLAUDE.md`（`@AGENTS.md`）自動載入本檔。

## 這類片是什麼

古代數學家穿著原本的服裝，在現代錄音室對著麥克風唱一首華語流行歌，用第一人稱唱自己的故事，靠「古人×現代器材×認真唱情歌」的反差吸引一般觀眾。單人主唱、一鏡到底的錄音室感，16:9，約 2.5～3 分鐘；說明欄補史實與傳說的分別。

## 規則

- 系列名稱與視覺自己設計，不沿用 THE FIRST TAKE／THE LAST TAKE 的名稱、片名卡樣式與灰藍背景布。
- 歌詞要有一句結尾的「自我揭穿」殺句（主角一路自述，最後一句反過來刺到自己）。
- 傳說（Eureka、鏡子燒船這類）在說明欄寫明是傳說或有不同說法，歌詞可以用「有人說」帶過。
- 生歌沒有 Suno 時用本機（MiniMax Music 3 或 YuE2），換引擎前先問使用者；生歌、拍片前先確認顯卡沒有被別的專案佔用。
- H3 鏡頭要鎖住時（`last_first` 尾幀＝首幀），同時要把 `camera` 改成鎖死（不推近）：預設的「緩慢推近」跟尾幀＝首幀互相矛盾，H3 會用疊影或硬拉近交差。（2026-11-18〈別碰我的圓〉C04、E01 疊上半透明大臉）
- 手大幅度掠過鐵鏽紅斗篷的鏡頭，H3 常把那塊顏色拖成紅色螢光殘影，約束寫「不准紅光」擋不住；改用 `"calm": true` 讓手不要掠過斗篷，再換 seed。（〈別碰我的圓〉V02、P01 兩輪都冒紅光）
- 動作會改變外觀的鏡（拿下耳機），用 `"last"` 寫結束時的樣子、先跑 `make_studio.py last` 生尾幀再拍：只給首幀會溶接或冒出第二副耳機，尾幀＝首幀又會把耳機戴回去。（〈別碰我的圓〉E01 拍四次失敗，加尾幀一次成功）
- 影子打在人身上不能是一條直線、也不會跟背景布幕上的影子連成一片（人是立體的、又站在布幕前方）；要影子就只放在布幕上。（〈別碰我的圓〉B02，使用者指出）
- 耳機、麥克風組這類一直出現的道具，生首幀前先備好道具參考圖（`../../docs/07_角色與首幀.md` §6），`studio.json` 的 `props` 列出，`frames`／`fix`／`last` 自動附。近景首幀的麥克風線寫「從麥克風底部垂直往下、直到畫面下緣都不碰桿子」；只寫「到桿子下段才靠上去」，近景會畫成彎去接桿子的弧線。（〈別碰我的圓〉17 鏡近景被退）
- `calm` 會把唱歌的嘴型一起壓小：唱歌鏡要避開紅光，改成雙手留在畫面外，不要加 `calm`。（〈別碰我的圓〉B04 嘴幾乎沒動被退）
- 開場走進來的全身鏡最容易壞（多一條腿、淡入第二層特寫、全身發紅光拖殘影）：約束寫「只有兩條腿」「一鏡到底、不淡入第二層畫面」，一次連拍 2 個 seed 再挑；兩側字卡（`title_card.layout: "sides"`）用 `end` 一路留到這鏡結束。（〈別碰我的圓〉O01 連三個 seed 各壞一種；字卡 7.7 秒就消失，使用者說來不及看）
- 拿下耳機的尾幀，線要照物理寫：耳機拿在胸前時，線從右耳罩出來搭在右手腕外側、再自然落到地面；寫「垂在身體前方」H3 會讓線穿過手臂。（〈別碰我的圓〉E01）
