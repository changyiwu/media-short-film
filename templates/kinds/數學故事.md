# 數學故事：類型規則

> 本類型的片放在 `output/數學故事/<片名>/`。這裡只放**這個類型**的規則；所有片共用的規則在上一層 `../AGENTS.md`，兩份都要讀。
> Claude Code 讀本資料夾的檔案時，會透過同資料夾的 `CLAUDE.md`（`@AGENTS.md`）自動載入本檔。

## 這類片是什麼

講數學家或數學史的短片，觀眾是學生（課堂播放或自學）。

## 規則

- **情節不偏離史料**：說法不一的（例如外號的由來）不當定論講，能拿掉就拿掉；史料沒記載的事（例如他怎麼想到的）不要編成史實，需要的話只做明顯的象徵畫面（不放人物）。（2026-10-19〈埃拉托賽尼的篩子〉，使用者要求）
- **教材和網路資料都要查**：先讀康軒備課 PDF 的對應課本頁與補充資料，再上網查史料（百科、館藏、學術或科普文章），兩邊對照後才訪談、編劇；網路說法互相矛盾、或只有科普文章轉述、找不到第一手出處的，在核對表標「相傳」或不採用。網址寫進核對表與角色 `README.md`。讀備課 PDF 用 `file-toolkit` 技能的環境（pypdfium2），不要用 Git Bash 的 `pdftotext`（中文抽不出來）。（2026-11-09〈普萊菲〉，使用者要求）
- 劇本附「史實與來源核對」表，每一項說法都寫依據（課本頁、古代文獻、通論）；另列「不是史料、是畫面需要的部分」（人物長相、對白、象徵畫面、現代數字寫法）。這張表要給使用者核對。
- 人物沒有留下肖像、場景沒有留下圖像的，片中疊「人物與場景為想像重現」。
- 數學內容與名詞照課本（康軒）；課本出處寫進核對表。對白是照步驟寫的，不要寫成「他說過的名言」。
- 數學家的台詞只能講他生前在做、可能知道的事；死後才有的事（墓誌銘、後人給的稱號、他的影響）一律交給旁白，人物不出場講。台詞是想像情節的，在劇本與核對表註明即可，台詞可以多寫幾句。（2026-11-07〈丟番圖的墓誌銘〉，使用者退掉「我活了幾歲？自己算吧」：活人不知道自己哪年死，死人不會說話）
- 結尾留給學生的題目，答案不能從片中畫面直接讀出來：圖上畫了直線、表格列了規律時，問方格或表格範圍外的值（例：圖只畫到 x＝8，就問 x＝21），讓學生要用方程式算；後製圖也不要畫出指到答案的虛線。（2026-11-08〈笛卡兒的坐標〉原問 x＝7，直線上就看得到 (7, 3)，使用者要求改題）
- 原書、館藏掃描照原樣用，不加遮罩、不塗改（遮罩會破壞原圖）；掃描上讀得到結尾題答案時，改結尾題，不改圖。（2026-11-10〈巴斯卡的算術三角形〉S13，原書圖畫到 (a＋b)⁹、讀得到原題答案 20，使用者退掉遮罩版、改問 (a＋b)¹⁰ 的係數總和）
- 劇本寫「在桌面上畫」「用手指比劃」這類不留痕跡的示意動作，觀眾會覺得怪；要畫就讓人物拿筆在紙上畫（H3 畫兩三條簡單直線沒問題）。（2026-11-08〈笛卡兒的坐標〉S6，使用者要求改成在紙上畫）
- 但畫的面（紙、沙盤）看得清楚時，H3 的線跟不上筆尖：筆已經畫過去，線才慢慢浮出來，而且畫出來的線沒有意義。兩種做法：鏡頭平視、看不到畫的面（〈畢達哥拉斯的三個正方形〉S3）；或首幀就把圖畫好，人物指著已經畫好的圖講解，不在鏡頭前畫新線。指著已畫好的圖用手指可以，這不是「空中比劃」。沙上的圖首幀要寫成「用棍子刻出來的溝，約一指寬、兩邊有推起的沙」，只寫 grooves 會生成像嵌在沙上的細線。（2026-11-14〈畢達哥拉斯的三個正方形〉S2，使用者退件）
- 旁白有「勾是三，股是四，斜邊是五」這種很短、排比的數字句，Ming 會重複、念亂（8 個候選全錯）：改成較完整的句子（「勾的長度是三，股的長度是四……」）再重生。（2026-11-14〈畢達哥拉斯的三個正方形〉S14）
- 旁白提到書名（《九章算術》）或引原文（「寫：正算赤…」）時，VoxCPM2 常整句換成另一種語氣：那句 8 個候選全都比其他句大聲 10 dB 以上（`voices` 會報「響度離群」）。遇到就在該句加 `"tts"`，把書名號、冒號換成逗號重生（字幕照原文），再挑語速跟其他句相近（每秒 3.3～3.9 字）的候選，不要直接放行。（2026-10-26〈劉徽的紅黑算籌〉S2、S5，使用者聽出語氣跟別段不一樣）
