# 08 換角重製（參考影片＋骨架控制）

> 2026-10-17 第一次走完：〈狗熊哆嗦毛〉16 秒片段的主角（真人）換成狗狗，動作、背景、畫風、聲音沿用原片，只把開頭台詞的「狗熊」換成「狗狗」。片子在 `output/換角重製/狗熊哆嗦毛_狗狗版/`（不進 git），完整紀錄看該片 `製作紀錄.md`。
>
> 跟 [02 端到端流程](02_端到端流程.md) 的差別：沒有劇本、鏡表照原片切鏡點；步驟 5–8 用 `tools/recast.py`＋片子資料夾的 `recast.json`（各鏡 spec 由它產生、交給 `tools/h3_shot.py`），**不走 `make_film.py` 的 h3 階段**（它不會把 `control` 傳給 H3）。

**授權**：參考影片、裡面的人聲都是別人的作品。成片只限自己看、非商用，沒取得授權不要公開；仿原聲的參考音與成品只放 `output/`，不進 git。片尾或貼文寫明改作自哪支影片。

## 流程

| # | 步驟 | 工具 | 產出 | 人工 |
|---|---|---|---|---|
| 1 | 擷取片段 | `yt-dlp`＋ffmpeg | `素材/原片_*.mp4`、`.wav` | ✅ 片段頭尾 |
| 2 | 分析：切鏡點、聲音哪段是人聲、燒進去的字卡 | ffmpeg `scene`／`silencedetect`、`tools/stt.py` | 鏡表（時間軸，24 fps 格數） | |
| 3 | 骨架控制影片 | `tools/pose_video.py`（ComfyUI 內建 RT-DETR＋SDPose） | `素材/pose/*.mp4`＋疊在原片上的預覽 | ✅ 骨架對位 |
| 4 | 新角色定裝 | `make_film.py chars`（[07](07_角色與首幀.md) §0） | 轉面圖＋表情表＋臉部近照 | ✅ 定裝 |
| 5 | 首幀：每鏡第一格把人換成新角色 | `recast.py first`（Image 2.5 編輯：原片格補成 16:9＋定妝兩張）→ 有發聲的鏡 `recast.py close-mouth` → `recast.py check` | `work/first/<id>.png`＋`_check.jpg`（疊骨架） | ✅ 風格 |
| 6 | 換台詞：仿原聲說新詞 | `recast.py voice`（VoxCPM2 兩種模式×N seed＋聽寫）→ `recast.py track <候選>` | 整條新音軌 | ✅ 挑一條 |
| 7 | 每鏡 H3 | `recast.py prep` → `recast.py run`（`h3_shot.py`：`control`＋`audio.fixed`） | `work/h3/<鏡>_<take>/` | ✅ 先試最難的一鏡 |
| 8 | 剪接成片 | `recast.py finish`（依時間軸剪、淡入、RTX VSR、疊字卡、換成新音軌） | `work/cut/film_1080p.mp4` | ✅ 驗收 |

## 各步重點

1. **擷取**：`yt-dlp` 報 403 先升級（`python -m pip install -U "yt-dlp[default]"`）並加 `--js-runtimes node`；`--download-sections` 也常 403 → 下載整支再用 ffmpeg 切。尾巴多出不要的聲音時，可以保留畫面、只把那段聲音淡出成靜音。
2. **分析**：`select='gt(scene,0.25)'` 找切鏡點（看起來像推鏡的，常常其實是切鏡）。原片多半是 4:3、30 fps：一律換算成 24 fps 格數排時間軸，成片就能跟原片逐格對齊。
3. **骨架**：`pose_video.py --start <舞蹈段起點> --end <終點> --no-face --feet --preview`。新角色不是人就 `--no-face`（人臉 68 點會把臉往人臉拉）；滑步、腳步重要就 `--feet`。只抽一次，之後依切鏡點切開各鏡用。
4. **定裝**：擬人動物先問清楚「像人還是像真動物」（見 `output/AGENTS.md` 的退件紀錄）。只改毛色時，拿已認可的轉面圖直接編輯改色，不要從文字重生（形狀、姿勢會跑掉）。
5. **首幀**：
   - 原片格先 `pad` 成 16:9（左右黑邊），提示詞要它把黑邊補成同樣的背景、拿掉字卡。
   - **大小與位置要寫死**：「頭頂跟原本的人一樣高、腳在原本腳的位置、前肢取代手臂並照抄位置」。不寫的話角色會比人大（實測頭高出約 130 px），骨架就對不上。
   - 每鏡首幀要照抄原片那一格的姿勢（舉手、弓步…），之後疊上骨架檢查。
   - Image 2.5 的遮罩不會嚴格遵守：整張都會重畫，背景板縫還會位移約 15 px。不要把原片像素貼回去（會出現接縫），直接用生成圖；背景「看起來一樣」，但不是原片的像素。
   - 原片燒進去的字卡要保留或改字：首幀與 H3 都不要畫字，最後後製疊（PIL 畫字卡 PNG，ffmpeg `overlay`）。
6. **換台詞**：從原片切出那一句（前後各留約 0.1 秒）當參考音，VoxCPM2 用**接續模式**（`prompt_wav_path`＋`prompt_text`＝原句文字，再加 `reference_wav_path`），每個 seed 都聽寫檢查。實測接續模式 6/6 正確，只給參考音常漏掉最後一個字。可以只換掉詞（從原音的音節低谷切開），也可以整句換掉，兩種都做給使用者聽。
7. **H3**：
   - 骨架鏡可以同時給 `control` 和 `audio.fixed`（原片那段聲音）：角色跟著動，嘴巴也跟著原片的發聲開合。說話鏡不用骨架，給首幀＋新台詞的固定音軌（DMAD 4 步）。
   - 短鏡照 [03](03_規則與踩坑.md) 至少生 5 秒：骨架用最後一格延長（`tpad=stop_mode=clone`），音軌補靜音，生完再剪回原長度。
   - 長的連續段（超過 158 格）在角色靜止的時候切開，下一段的首幀＝上一段最後用到的那一格，接點就看不出來。
   - 實測（RTX 5060 Ti）：骨架鏡 14 步、124 格約 10–11 分鐘，141 格約 12 分鐘；說話鏡 DMAD 124 格約 3.5 分鐘。
8. **成片**：各鏡剪到時間軸格數 → 接起來 →（原片有淡入就補上）→ RTX VSR 放大 → 疊字卡 → 換成新音軌（H3 生的聲音不用）。片尾預設不加（[02](02_端到端流程.md) §12）。

## recast.json 與 recast.py

一支片一份 `recast.json`，放在片子資料夾，裡面的路徑都相對於片子資料夾。完整範例見 `tools/examples/recast.json`（〈狗熊哆嗦毛〉狗狗版）。同一支原片要做別的角色版本時，複製一份，改這幾項：`char`、`edit`、`firsts` 的姿勢句、`line.text`、`track`、`h3.subject`、`finish.caption.text`。

| 欄位 | 內容 |
|---|---|
| `source`／`source_audio` | 原片片段（影片／聲音） |
| `char` | `film.json` 的 `chars` key：首幀用它的 `look`，參考圖預設 `work/chars/<key>_turn.png`、`_expr.png` |
| `pose` | 骨架影片＋它在原片的起點秒數（步驟 3 抽的那一支） |
| `line` | 要換的台詞：參考音、原句文字、新詞、原句起訖秒數（只換詞再加 `word_end`） |
| `track` | 選定的新音軌（`track` 子命令產生，挑好後填進來） |
| `edit` | 首幀換角提示詞的名詞：畫面是什麼、原本的人、新角色、補黑邊用的背景 |
| `firsts` | 每張首幀：原片秒數＋姿勢句 |
| `h3` | 各鏡共用：style、setting、soundscape、`subject`、constraints、`min_dur`（短鏡至少生幾秒） |
| `shots` | 時間軸：`frames`（24 fps 的起訖格）、`first`（首幀 id，或 `after:<鏡>`＝上一鏡最後用到的那一格）、`control`（預設 true）、`draft`、`camera`、`action`、`dialogue`、`vocals`、`seed`、`take` |
| `finish` | `fade_in`（秒）、`caption`（字卡文字、出現時間、位置與顏色，座標以 1344×768 為準） |

- 在片子資料夾跑 `python ../../../tools/recast.py <子命令>`。`voice` 會自動換成 `PY_VOICE` 來跑，`run`、`finish` 的 H3、VSR 會自動換成 `PY_H3`，不必先切換 venv。
- `prep --take t2` 寫到 `work/h3/<鏡>_t2/`，不會蓋掉舊的那一版。決定用哪一版之後，在 `recast.json` 那一鏡寫 `"take": "t2"`，`finish` 就會用它。
- 鏡的 `"vocals": "auto"`：從那一鏡的音軌切段偵測有聲音的時段（-30 dB），寫成 `h3_shot.py` 的 `vocals`。沒寫 `vocals` 時，沒有台詞的固定音軌會被描述成「只有環境音」。

## 有發聲的骨架鏡：嘴要跟著動

狗狗版第一次做的時候，除了說話鏡 A，其他舞蹈鏡在發聲時嘴巴都沒有開合，一直張著嘴笑。在 B2 一次只改一項來測試：

| 版本 | 改了什麼 | 嘴型 |
|---|---|---|
| t1 | 原本做法（提示詞說音軌「只有環境音」，首幀張嘴） | 一直張嘴笑 |
| t2 | 加 `vocals`（描述有發聲、嘴要動），同一個 seed | 跟 t1 幾乎一樣 |
| t3 | 發聲照聽寫寫成台詞「嘟咚！咚匡！隆咚嘟咚！」，同一個 seed | 跟 t1 幾乎一樣 |
| **t4** | t3＋**閉嘴首幀**＋換 seed | **會開合**，動作照樣跟著骨架 ✅ |

做法：
1. **聽寫發聲**：用 `tools/stt.py`（`load_asr()`）**不要給提示詞**，聽到的字最貼近原音（例如「冻矿冻矿」「弄动框」）。`stt.py` 命令列的預設提示詞會讓 Whisper 聽出不存在的字，給「隆冬匡…」當提示詞則會被牽著走。
2. **寫成台詞**：把聽寫結果換成狀聲詞（例如「咚匡！咚匡！」），寫進那一鏡的 `dialogue`；`action` 寫明從幾秒到幾秒在發聲、其他時候閉嘴。
3. **閉嘴首幀**：`recast.py close-mouth <首幀 id> --box <嘴部範圍>`。Image 2.5 即使給了遮罩也會整張重畫：角色大小、位置偏掉，顏色也變飽和。H3 照首幀生成整鏡，於是整鏡的顏色與動作都會跟原本不同（狗狗版 B2_t4 被退件；B1a 的狗變小，導致接續的 B1b 第 1 格跳）。所以工具只取生成圖的嘴部，對齊後貼回原首幀，嘴巴以外逐像素不變。對齊分數低於 0.6 會警告。要重貼不用重生：加 `--reuse`。
4. **換 seed** 重跑。用同一個 seed 時，嘴型會被原本那一版綁住。
5. 換了 seed 的接續鏡（`"first": "after:<鏡>"`）要逐格看接點。狗狗版 B1b 換 seed 後，第 1 格就跳掉（前肢從胸前變成垂下、狗變大），只好再換一個 seed 重跑。

`firsts` 的姿勢句不要寫 mouth open：張嘴的首幀會讓 H3 整鏡都維持張嘴。
