# 07 角色與首幀

> 本篇分三部分：**§0 是預設做法**（OpenAI 生圖：`gen_image.py` 預設 Image 2.5 API 優先、Codex CLI 次之，提示詞裡的 `<image1>` 會自動改成「Image 1」）；**§1–2 是本機千問備選**，整支片指定 `IMAGE_BACKEND=local`（或單張 `--backend local`）時用，該兩節的指令都要加 `--backend local` 才會固定在本機跑；**§3 起兩者通用**。預設失敗時會停下，不會自動改用本機。

上游原專案的首幀是用雲端的 OpenAI Image 2.5 生的；上游 repo 改為預設全本地，§1 起的本機做法都是 2026-10-07 在三種硬體配置下實測過的。

> 下面的 `"%PY_H3%"` 是 ComfyUI 的 Python，先在同一個 cmd 視窗 `call <repo>\configs\profile.cmd` 才有（Comfy Desktop 的 `.venv` 或 `C:\AI\H3\venv`）。

## 0. 預設：OpenAI 生圖的轉面圖＋表情表＋臉部近照

`make_film.py chars` 在預設的 OpenAI 生圖（Image 2.5 API 或 Codex）下，每個角色一次生三張多格定妝（2026-10-17 已用 Image 2.5 API 跑過轉面圖＋表情表的 `make_film.py chars masters frames`、2026-10-24 補生臉部近照，結果見本節最後〈實測〉）：

| 檔案 | 內容 | 怎麼生 |
|---|---|---|
| `chars/<角色>_turn.png` | 轉面圖：一排四個全身（正面、3/4、側面、背面），灰底 | 純文字生成，是這個角色的基準 |
| `chars/<角色>_expr.png` | 表情表：3×2 六格半身（平常、笑、生氣、驚訝、難過、思考），灰底 | 附轉面圖當參考生成，確保同一張臉 |
| `chars/<角色>_face.png` | 臉部近照：左右兩格肩膀以上（左正面、右 3/4；3/4 朝哪邊模型自己決定，不影響長相），平常表情，灰底 | 附轉面圖＋表情表生成；臉夠大，給特寫看清五官 |

- 三張都要人看過再往下做：轉面圖四格是不是同一個人、服裝前後一致；表情表、臉部近照是不是轉面圖那張臉（近照兩格要同一個人、跟表情表「平常」那格像）。不滿意就刪檔、在 `film.json` 的 `seeds` 加 `char_<角色>` 重生（Image 2.5、Codex 都不吃 seed，重生就會不同）；重生轉面圖時後兩張也要刪掉重生。
- 臉部近照只放兩格：格子越多臉越小，就失去近照的意義；側面、背面轉面圖已有，表情交給表情表。
- 首幀每個角色附幾張，由每鏡的 `sheets` 決定（1–3 張，沒寫＝轉面圖＋表情表）。提示詞會寫明「只參考長相與服裝，不要照抄格子版面、灰底與姿勢」。如果首幀還是變成拼貼，先回報再改提示詞。依景別挑：

| 景別 | `sheets` | 理由 |
|---|---|---|
| 全身、寬景、背影、側身走位 | `["turn", "expr"]`（預設）或只 `["turn"]` | 要服裝、鞋子、身形與側背面；臉小，近照用不到 |
| 中景、中特寫 | `["turn", "expr", "face"]` | 臉和服裝都看得到 |
| 特寫、大特寫 | `["face", "expr"]` | 五官細節靠近照，表情靠表情表 |
| 雙人以上同框 | 每人 1–2 張，例：`{"chen": ["face"], "zhe": ["turn"]}` | 參考圖越多每人比重越被稀釋，只給該角色在這鏡最需要的 |

- 表情表每格的臉比單張小，`img25.py` 送出前又會把參考圖縮成約一半面積；特寫臉不夠像時先附 `face`，還不像再設 `IMG25_REF_SCALE=1` 重生比對。
- 這三張**不能**拿給本機 Qwen 當參考（會照抄成拼貼）。改走本機時整支片設 `IMAGE_BACKEND=local`，改用下面 §1 的單張半身照。
- 只改毛色或服色：拿已認可的轉面圖當參考圖，用 `img25.edit()` 改色、寫明其他全部不變，再附新轉面圖重生表情表（2026-10-17〈狗熊哆嗦毛〉狗狗定裝，改色後形狀姿勢完全不變）。
- `img25.edit()` 的遮罩只是提示，不會嚴格遵守：整張都會重畫。要保留原圖像素的做法行不通（見 [03](03_規則與踩坑.md) §8）。
- 外觀描述要寫下半身與鞋子：沒寫時轉面圖會自己配（實測老師配了卡其褲＋白球鞋、學生配了深藍百褶裙＋黑皮鞋），之後每張全身鏡都會照它，等於模型替你決定了服裝。

**實測（2026-10-17，Image 2.5 API）**：用 `pipeline/demo_local/run_demo.py` 的同一組角色描述（林老師、小芸），重做示範片裡老師「正面單人」（S2）和「雙人、老師側臉」（S4）兩鏡，跟本機千問那條路比。
- **千問＋單張正面半身**（run_demo）：S2 像，S4 的老師像換了一個人（臉變長、老了約十歲、髮型不同）。H3 只是沿用首幀，所以問題出在首幀：參考圖只有正面，側臉只能猜；雙人鏡附兩張參考圖，長相又被稀釋。
- **Image 2.5＋轉面圖＋表情表**：轉面圖四格是同一個人（含側臉與背面），表情表六格是同一張臉；S2、S4 的老師年紀、髮型、眼鏡一致，S4 的側臉跟轉面圖的側面對得上；學生也一致。首幀沒有照抄格子版面或灰底，沒出現拼貼。
- 費用與時間：2 個角色 4 張定妝＋1 張母版＋2 張首幀，共 7 次 API，約 2 分鐘。沒用到 `IMG25_REF_SCALE=1`。
- 檔案在 `output/測試/測試_多格定妝/work/`（不進 git），並排比較圖是 `work/first/_compare_qwen_vs_img25.jpg`。
- **臉部近照（2026-10-24，Image 2.5 API）**：用 `chars` 同一段提示詞，附三個既有角色（兩位老年希臘數學家、一隻真狗比例的狗）的轉面圖＋表情表生成，每張約 18 秒。三張的兩格都是同一張臉，跟表情表「平常」那格一致（髮型、鬍子、服裝、毛色、耳形），沒有拼貼。提示詞指定 3/4 朝畫面左，結果兩張朝右、一張朝左，所以不再指定方向。首幀附近照的效果尚未實測。

## 1. 本機備選：單張半身定妝照

用 Qwen-Image 2.1 生一張「灰底、正面、半身、只有一個人」的照片，當這個角色之後所有畫面的參考。

```
"%PY_H3%" <repo>\tools\gen_image.py --width 1024 --height 1024 --seed 11 --out chars --prompt "Studio character reference photo, single person only, one image (not a collage), medium close-up bust portrait facing the camera, plain light grey seamless background, soft even studio light, sharp focus, realistic photograph. <角色外觀：年齡、臉、髮型、眼鏡、服裝>, gentle natural expression. No text, no watermark."
```

- **只能一格**。我們試過把「三格定妝照」（全身＋半身＋臉）當參考圖，Qwen 會把整張的版面照抄，生出拼貼圖。
- 外觀描述寫具體（年齡、臉型、髮型、眼鏡、上衣**與下半身**的顏色款式），之後每一鏡的提示詞都照抄同一段。沒寫下半身，全身鏡會隨機配裙子或長褲。
- 同一個 seed 不滿意就換 seed 多生幾張，挑一張定案，之後不要再換。

## 2. 本機生首幀：兩種做法

| | A. Qwen-Image-Edit 附參考圖（本機預設） | B. Qwen-Image 2.1＋角色 LoRA |
|---|---|---|
| 要不要訓練 | 不用 | 每個角色一次：產生訓練圖約 20 分鐘＋訓練（5090 模擬 16GB＋32GB 實測 33 分鐘；真實 16GB 卡推估 1–1.5 小時） |
| 長相像不像 | 像 | 最像 |
| 會不會照劇本演（景別、動作、側臉） | **會** | 會 |
| 輸出 | 直接 1344×768（H3 要的尺寸） | 2K（2688×1536），細節最好，縮成 1344×768 再給 H3 |
| 多人同框 | 最多 3 張參考圖（`<image1>`～`<image3>`），2 人實測可行 | 兩個 LoRA 同時掛會互相稀釋 → 先出構圖、再用 `qwen21_face_refine.py` 逐人重繪 |
| 每張時間（5090） | 附 1 張參考圖約 47 秒（16GB 卡模擬約 50–55 秒）；附 2 張（定妝照＋場景母版裁切）約 85 秒 | 約 57 秒 |

**不要用的做法**：Qwen-Image 2.1 直接附參考圖（不訓練）。長相會像，但每張都變成跟參考圖一樣的正面置中姿勢，要求「側臉看窗外」也照樣正面。

### A. Qwen-Image-Edit 附參考圖

```
"%PY_H3%" <repo>\tools\gen_image.py --model qwen-edit --ref chars\yun.png --width 1344 --height 768 --seed 5101 --out first --prompt "Keep exactly the same person as <image1>: same face, hairstyle and clothes. New photo: <電影感句> <這一鏡：景別、角色在哪、做什麼、表情> No text, no watermark, no captions."
```
雙人鏡：`--ref A.png --ref B.png`，提示詞寫「the man from <image1> ... the girl from <image2> ... Only these two people.」

### B. LoRA

1. 產生訓練圖（用 A 的方法換景別、角度、表情、場景）：
   ```
   "%PY_H3%" <repo>\tools\make_lora_dataset.py --ref chars\yun.png --trigger yun_local --desc "the girl Xiaoyun, a bright 11-year-old Taiwanese schoolgirl with a short black bob ..." --out datasets\yun
   ```
2. **逐張看，刪掉臉不像、多手多腳、有字的圖**（原專案每個角色都這樣做）。
3. 照 `setup/lora/README.md` 用 AI Toolkit 訓練（768 解析度、rank 32、1600 步）。2026-10-07 已用示範片角色「小芸」從零走完這條路（本機定妝照→本機訓練圖→16GB＋32GB 模擬下訓練→首幀），三個場景都像本人。
4. 生首幀：`gen_image.py --lora yun_local.safetensors:1.0 --prompt "yun_local, the girl Xiaoyun, ... <這一鏡>"`；提示詞一定要放觸發詞和外觀描述。

## 3. 首幀提示詞的固定寫法

照 `tools/examples/qwen21_prompt_template.txt`（電影感範本）：
- 開頭固定：`A cinematic film still from a Taiwanese coming-of-age movie, shot on Kodak Vision3 500T film with an anamorphic 50mm lens at f/2`
- 光線要寫具體（例：夕陽從窗外低角度照進來、逆光、髮緣輪廓光、空氣中的光束、琥珀色調色）。只寫 soft daylight 會變成平淡的白光。
- 背景一句話帶過、保持簡潔；逐項列出房間裡的東西會讓畫面雜亂。
- 結尾固定：`No text, no watermark`；要乾淨的黑板就寫 `a green chalkboard with nothing written on it`。

## 4. 場景一致

- 同一個場景的多個鏡頭，先生一張空場景母版，之後每一鏡把母版**裁成想要的景別**再當參考圖附上（附整張會照抄成大全景）。
- 不要附別支片的完成畫面當「風格參考」：Qwen 會把裡面的人物和物件也畫進來。

## 5. 示範

`pipeline/demo_local/run_demo.py` 用做法 A 從零做出兩個角色和 4 鏡首幀，再一路做到成片；在「16GB 顯卡＋32GB 記憶體」模擬條件下實測可完整跑完。
