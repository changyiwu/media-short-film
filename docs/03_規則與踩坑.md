# 03 規則與踩坑

每條規則都來自一次實際退件或實測。理由寫在後面，改規則前先看理由。

## 1. 劇本

| 規則 | 理由 |
|---|---|
| 16:9、24fps、每支獨立成篇 | 頻道規格；24fps 也是將來訓 LoRA 的前提 |
| 開寫前先問齊人物、場景、走向、風格、禁則 | 最大的浪費是批次生成完才發現共通缺陷 |
| 先給 2–3 個敘事方向再寫 | 一次驗收合格的片都是這樣開始 |
| 寫看得見的行動；反轉要能從前文線索回看成立 | 不要用解說對白代替戲 |
| 技術限制就是寫作限制：避開快打、追逐，一鏡一人說話 | H3 多人對話容易配錯嘴，快動作會崩 |
| 喜劇用「神話層 × 真相層」，靠切鏡製造反差 | 只靠旁白解釋笑點的版本被退件 |
| 頻道、場域、角色專屬的禁則（例：某類角色不碰觸、不用手機）寫在 `output/AGENTS.md`，不寫進本檔 | 本檔只放所有片都適用的規則 |
| 總結句用簡單常用字 | TTS 比較不會念錯 |

## 2. 空間與構圖

| 規則 | 理由 |
|---|---|
| 教室方位固定：黑板在前、學生面向黑板、窗在學生左手邊 | Image 2.5 自由構圖曾讓學生背對黑板 |
| 布置圖當 Image 2.5 參考，提示詞寫「只抄機位與站位，不抄方塊外觀」 | 鎖住空間 |
| 不同視角的首幀從**同一張底圖**編輯；首尾幀也從同一張圖改 | 換機位後背景會跑掉 |
| 不讓人物橫向走，改原地轉身 | H3 會跟拍，桌椅跟著滑 |
| 空景、時鐘、桌面特寫用靜圖＋慢推 | H3 會自己加人或切走 |
| 單人鏡提示詞完全不提其他人；多人鏡寫 `Exactly N people` | 提到誰誰就會冒出來 |
| 主角腰上或更近（臉佔畫高 10% 以上） | 768p 全景臉糊，放大救不回 |
| 提示詞必寫 `NO black letterbox bars` | 電影感提示詞會自帶黑邊 |

## 3. 角色一致性

| 規則 | 理由 |
|---|---|
| 每個角色一組：轉面圖（正側背 3/4）、6 格表情表、臉部近照（正面＋3/4 兩格）、**鎖定提示詞** | 每次照抄鎖定提示詞，不自己重寫外觀 |
| 首幀依景別每個角色附 1–3 張定妝（`sheets`）：全身鏡不附近照、特寫鏡附近照、雙人鏡每人少附 | 近照的臉夠大才看得清五官；參考圖越多每人比重越被稀釋 |
| **本地生圖的參考圖只能是單張半身照**，不能用多格定妝表 | Qwen 會把多格版面照抄成拼貼 |
| 本地首幀不訓練時用 Qwen-Image-Edit 附參考圖；不要用 Qwen-Image 2.1 附參考圖 | 2.1 附參考圖會鎖死成參考圖的正面姿勢 |
| 生圖時以轉面圖＋表情表（特寫加臉部近照）當 Image 2.5 參考圖（2026-10-15 起預設，2026-10-17 實測見 [07](07_角色與首幀.md) §0；提示詞要寫明不要照抄格子版面） | 比 LoRA 簡單；側臉、背面、全身、表情鏡有依據 |
| 頭套寫「素色美洲獅、無條紋、無斑點、無鬃毛、布偶繡眼」 | 不寫會變老虎 |
| 頭套加「a lifeless prop whose sewn face and eyes never move」 | H3 會讓道具眨眼 |
| **多人鏡只給首幀**，不加 H3 身份參考圖 | 加了會多一個人 |
| 單人鏡才加身份參考，並寫明「只是外觀參考，不是要切過去的畫面」 | 否則 H3 會自己切鏡 |
| 低頭、轉身、再露臉 → Image 2.5 生尾幀鎖住 | 否則臉會換人 |
| 小孩要明顯是 11–12 歲（寫 childish face, never a teenager） | 第一版小雯像 16 歲 |
| 換角重製的首幀寫死大小與位置：頭頂跟原本的人一樣高、腳在原本腳的位置、前肢照抄手臂位置 | 不寫時角色比人大（頭高出約 130 px），骨架對不上（[08](08_換角重製.md)） |
| 只改角色毛色／服色：拿已認可的轉面圖直接編輯改色，不要從文字重生 | 重生會連形狀與姿勢一起變 |

## 4. H3

| 規則 | 理由 |
|---|---|
| 一律用 `h3_shot.py`（官方 Ref2VA 六段格式＋格式檢查） | 規格一致；手寫容易漏段、標籤錯 |
| 預設只給首幀；長連續動作或一定要演到某個結果才加尾幀 | 對話與換場靠切鏡 |
| 尾幀機位構圖與首幀完全一樣，但**必須是不同的圖**；人要動時尾幀畫「動作完成後的姿勢」 | 構圖不同會搖鏡去對；同一張圖會把人鎖回原姿勢、畫面凍住（`h3_shot.py` 會提醒） |
| 沒鎖尾幀加「LOCKED-OFF STATIC CAMERA on a tripod」 | 否則鏡頭自己漂走 |
| `draft: true`（DMAD 4 步）是日常定稿；抽到就用，不要同 seed 改 14 步重生 | 8 類鏡頭並排看不出差、快 49–58% |
| 14 步留給：骨架舞蹈、群舞、細膩表情、Combat LoRA 拉滿 | 這幾類 DMAD 動量偏少或未驗證 |
| 特效「碎掉／消失」加 Image 2.5 尾幀 | 只給首幀 H3 不會做 |
| 定稿不開 EasyCache | 近景糊、靜止鏡出油畫雜訊 |
| 單鏡 ≤12 秒（約 294 格）；短插入鏡也至少生 5 秒再剪 | 15 秒會漂移、自己切鏡 |
| 不說話的臉給靜音引導音軌 | 否則會嘟囔 |
| `action` 寫 50–120 個英文字：Starting from <Picture 1> → 動作開始 → 發展 → 結果，寫身體部位、幅度、次數，不寫抽象形容詞（[02](02_端到端流程.md) §5〈動作寫法〉） | 一句話版動作量只有官方結構的 1/2.7（上游 2026-10-23 光流實測） |
| 動作鏡首幀畫「動作開始前」的姿勢；全身大動作留頭頂空間 | 首幀已在動作最高點，H3 只剩維持可演 |
| 大動作鏡、背景容易冒人的鏡：可在 `action` 前加 2–4 句首幀描述（選用，效果未確認） | 上游補測畫面較釘在首幀；本機 2 seed 實測背景偏差少約 20%，但動作量也少 12–18%，頭照樣碰頂（[02](02_端到端流程.md) §5） |
| ⚠ 已知問題：H3 快動作時上半身可能暴成橘黃色塊（原因未查），大動作鏡要逐格看 | 2026-10-31 本機（ComfyUI 0.42.5、DMAD 4 步）跳躍鏡 4／4 支都出現，每支 0.25–1.1 秒；`review.py` 雜訊檢查抓不到 |
| 動作要「說到那個字的瞬間」發生（寫進提示詞） | 否則起立、敬禮慢半拍 |
| 長音：提示詞寫長音秒數＋「嘴維持張開到聲音結束」 | H3 會提早閉嘴 |
| 舞蹈：一鏡到底＋骨架控制＋首尾幀，最長 158 格 | 切片或用特寫避開都被退件 |
| 骨架鏡可同時給 `control` 與 `audio.fixed`（原片那段聲音） | 動作照骨架（2026-10-17 換角重製）；嘴要跟著發聲動，見下一條 |
| 骨架鏡的發聲（喊拍子、吟唱）要聽寫成狀聲詞寫進 `dialogue`，首幀改成閉嘴，再換 seed | 只改提示詞（`vocals` 或台詞）同一個 seed 嘴型不變；首幀張嘴，H3 就整鏡張嘴（[08](08_換角重製.md)〈有發聲的骨架鏡〉） |
| 骨架鏡太短：骨架最後一格延長（`tpad=stop_mode=clone`）、音軌補靜音，生 ≥5 秒再剪 | 照「短插入鏡也至少生 5 秒」 |
| 連續段超過 158 格：在角色靜止時切開，下一段首幀＝上一段最後用到的那一格 | 接點看不出來 |
| 動作 LoRA：Combat_V2 0.7、GunFu 0.9 | 實測有效；要保住首幀時避開 Motion_Repair 高強度 |
| H3 不要和別的 GPU 工作同時跑 | 搶顯存，慢約 10 倍 |
| 計時看 ComfyUI `/history` 的執行時間，不看牆鐘 | 佇列共用時牆鐘不準 |
| 不換成社群微調模型 Singularity V2 | 上游 2026-10-24 A/B（6 鏡 × 2 seed＋動作鏡 14 步）：動作大 1.5–2.4 倍、速度一樣，但參考音比較不像本人（雙人鏡 0.45–0.61 → 0.32–0.42）、推掌鏡 3／3 支把首幀後牆換成寫滿中文的黑板、配角換臉、暖光變冷藍。要動作大，改 `action` 寫法就有 ×2.7 |
| SelfLift 兩段採樣（前段低解析、後段全解析）暫不用 | 上游評估：只省時間不加畫質；DMAD 只有 4 步可省的少；外掛沒有授權檔 |

## 5. 配音與發音

| 規則 | 理由 |
|---|---|
| **畫面內的角色台詞預設由 H3 自己念**（`voice_mode: "h3_ref"`）：VoxCPM2 設計角色參考音 → H3 拿它當音色參考念台詞 → `h3` 結尾聽寫比對原文；念錯換 seed 抽 2–3 次，還錯就那句改 `"voice_mode": "fixed"` | 2026-10-24 使用者決定改預設：表演與語氣比固定音軌生動；三句實測都念對（[02](02_端到端流程.md) §5）。H3 會改用詞、讀音替換表對它無效，所以下面的讀音規則只管 `fixed` 的句子與旁白 |
| **配音引擎 VoxCPM2**（`make_voxcpm.cmd`；`make_film.py` 內建）：角色參考音、旁白，以及 `fixed` 的台詞（VoxCPM2 念每句、當 H3 固定音軌） | 2026-10-14 起：官方不限平台，桌機與 RTX Spark 筆電同一套；Apache-2.0 可商用 |
| 仿原聲換詞：VoxCPM2 接續模式（`prompt_wav_path`＋`prompt_text`＝原句文字＋`reference_wav_path`），每個 seed 都聽寫 | 2026-10-17 實測接續模式 6/6 正確；只給參考音常漏掉最後一字 |
| 角色參考音定了就不要換（已公開的角色換聲音觀眾聽得出來） | 聲音是角色的一部分 |
| 參考音不要升調或變速處理 | 處理過的參考音會念不準 |
| 成品不用 Edge-TTS，它只當「標準台灣國語答案卷」 | 聲音不夠自然 |
| VoxCPM2 的台詞先繁轉簡再送（`voxcpm_batch.py` 已自動處理，字幕仍用原文） | 繁體字讀音較不穩 |
| 每句 8 個候選，`voice_pick.py` 自動挑：聽寫的**拼音＋聲調**要全對（同音字不算錯），有聲長度合理，再比台灣國語腔調分數 | ASR 只驗字，抓不到聲調；ASR 常把角色名寫成同音字 |
| 挑音也看音量音質：響度跟同角色所有候選的中位數差超過 6 dB、或 4 kHz 以上能量比異常高（> max(0.30, 中位數×3)，嘶聲）的候選不選；`picks.json` 記 `lufs`、`hf_4k`；聽寫對的全都異常時照舊挑、標 `needs_review`（`review_reason: "sound"`），`voices` 會停下要人聽 | 2026-10-19〈歐幾里得的完美數〉只看聽寫與腔調，挑到大 10 dB、音色不同與高頻 63% 的候選，旁白忽大忽小、音質不一被退件 |
| 各句原始響度差超過 6 dB（不同角色、不同聲音設計常差 10 dB 以上）就在 `mix` 加 `voice_lufs`（例 −20）；`voices` 會提醒 | 同一支片旁白原始響度 −25.8～−43.8 LUFS，不拉平就忽大忽小 |
| 每句配音混音前先過 highpass 70 Hz、lowpass 11 kHz、adeclick（`cut` 自動做）；最後限幅用 4 倍超取樣，並量編成 AAC 後的真峰值，超過 −1.2 dBTP 就自動壓低限幅門檻 | 旁白開頭「他」的爆破音在取樣點之間衝高，真峰值 −0.7 不合格，降 `target_lufs` 也沒用 |
| 多音字、英文詞念錯：加進 repo 根目錄的**讀音替換表 `tts-lexicon.md`**（`\| 原文 \| 改寫 \| 說明 \|`，例：奇數→基數、GPT-4→GPT four）；只對某支片的放片子資料夾的同名檔 | `voxcpm_batch`、edge-tts 答案卷、`voice_pick` 聽寫比對都套同一張表，字幕照原文；四個 TTS 相關 repo 各一份、內容相同，同層時合併讀取，改表時四份一起改（`tools/tts_lexicon.py --sync`） |
| 只有這一句念不準的字**改同音字**，寫在 `film.json` 該句的 `"tts"`（例：掃→嫂、綜→縱），字幕用原文 | VoxCPM2 不支援注音標記（`voxcpm_batch.py` 會拿掉標記並警告） |
| 阿拉伯整數會自動轉國字；小數、英文縮寫、符號請寫成國字 | VoxCPM2 在本專案關掉文字正規化（`normalize=False`） |
| **單字台詞（例：「考。」「接！」）盡量改成兩三個字** | VoxCPM2 單字常念成亂音；單字喊叫 ASR 也常聽成別的字（「接」→「姐」），只能人耳判斷 |
| 聽寫（ASR）不對的候選一律不准選；抽 8 個都不對就改台詞 | 否則挑音程式會從一堆錯的裡挑一個 |
| 挑音的「標準台灣國語答案卷」用 edge-tts；沒網路才用 VoxCPM2 設計出來的播報聲音 | 上游實測設計聲音版跟 edge-tts 挑出的第一名只有 4/19 句相同，原專案驗收過的是 edge-tts |
| 重要句最後請人聽一次 | 自動量測在小音量下不可靠 |
| 每幕檢查台詞時間軸有沒有重疊 | 旁白曾和廣播疊在一起 |

## 6. 音效與配樂

| 規則 | 理由 |
|---|---|
| 有動作、**而且看不到嘴**（背影、腳、手、遠景）的鏡頭，可以用 H3 原生音效（spec 不寫 `audio` 欄位） | H3 的腳步聲和畫面逐格同步 |
| **看得到臉的鏡頭一律給固定音軌或角色參考音**（有台詞：`h3_ref` 給參考音、`fixed` 給配音；沒台詞給靜音），就算有動作也一樣；需要動作音效時，另外用同一張首幀拍一支原生音效版，ASR 確認沒有人聲後只取它的音軌，或用音效庫 | 看得到臉時 H3 原生音效會讓角色自己嘟囔（2026-10-07 實測：翻書包鏡冒出「你去考古啊」） |
| H3 做不出的用 CC0 音效庫（repo 的 `sfx/`，58 個 Freesound CC0），不用程式合成腳步、肚子叫 | 合成的很假 |
| 配樂純器樂，`[Instrumental]` 約 14 個，分離後再用 | 會夾人聲、太短 |
| 台詞前後壓配樂 | 戰鬥配樂會蓋過台詞 |
| 停頓處墊很輕的房間聲；不要低頻隆隆聲 | 偏好 |
| 用了 MiniMax Music 3 要在片尾列名並註明 AI 生成 | 授權要求 |

## 7. 放大

| 規則 | 理由 |
|---|---|
| 近景、中景：768p＋RTX VSR ULTRA | 秒級、不改表演 |
| 全景、舞蹈：FlashVSR，逐鏡檢查多畫的細節 | 較銳，但會幻覺細節 |
| 不用 SeedVR2、SoL-Refiner | 會改臉、改嘴型、改時鐘 |
| 不用 VOSR2 逐格修臉（社群「H3 臉部修復」工作流的做法） | 上游評估：是單張圖片超解析、不看前後格，跟 SeedVR2 同類風險 |
| 字幕不要先燒進低解析再放大 | 字會糊 |

## 8. 後製與剪接

| 規則 | 理由 |
|---|---|
| 畫面上的中文一律後製；考卷等「道具上的字」由 Image 2.5 直接畫再逐字核對 | H3 寫字會變亂碼 |
| 原片燒進去的字卡要保留或改字：首幀與 H3 都去掉，後製用 PIL 畫 PNG 再 `overlay` | 生成端畫中文不可靠，後製每鏡一致 |
| Image 2.5 生成圖不要貼回原片像素 | 遮罩不會被嚴格遵守，整張重畫、板縫位移約 15 px，貼回會有接縫 |
| 用 `ss` 裁掉開口前空白，不要拉長整鏡 | 尾巴會被切 |
| 同機位接續的對話鏡加 0.3 秒溶接 | 避免跳接 |
| 施法換場景要有魔法轉場（漩渦＋光點＋光環） | 不能只硬切背景 |
| 變臉用光流變形或 H3 首尾幀連續變化 | 遮罩擦過去看起來像剪接 |
| 遠景短、特寫多；動作定格後直接接反應鏡 | 節奏 |
| 審片附手機版 720p（<30MB） | 驗收的人在手機上看 |

## 9. 踩坑 Top 25

| # | 坑 | 對策 |
|---|---|---|
| 1 | EasyCache 讓近景糊、近乎靜止的無聲鏡出油畫雜訊 | 定稿不開快取 |
| 2 | 首尾幀用同一張圖 → 畫面幾乎凍住 | 尾幀必須是不同的圖 |
| 3 | 沒鎖尾幀，鏡頭自己搖走 | 三腳架固定句，檢查首尾格構圖 |
| 4 | 尾幀構圖和首幀不同 → H3 搖鏡去對 | 首尾幀從同一張圖編輯，只改動作 |

## Windows 小坑

- ffmpeg 9 不支援 `-filter_complex_script`，改 `-/filter_complex`。
- cmd 的 `set X=1 && 下一個指令` 會把空白一起存進變數（Python 遇到 `PYTHONUTF8="1 "` 直接拒絕啟動）：寫成 `set "X=1" && …`。
- `cmd /c "call configs\profile.cmd && %PY_H3% …"` 的 `%PY_H3%` 在 profile 執行前就展開成空字串：直接寫 Python 的完整路徑，或改用 `cmd /v:on` 與 `!PY_H3!`。
- `yt-dlp` 報 403：先 `python -m pip install -U "yt-dlp[default]"`、加 `--js-runtimes node`；`--download-sections` 常 403，改下載整支再用 ffmpeg 切。
- drawtext 字型路徑的冒號要跳脫：`C\\:/Windows/Fonts/...`。
- faster-whisper 缺 cuBLAS DLL：把 venv 裡 `nvidia/*/bin` 加進 DLL 路徑（`stt.py` 的 `_add_cuda_dll_dirs()`）。
- 標楷體用 `kaiu.ttf`；`mingliub.ttc` 是 ExtB 字集，一般字會變方塊。
- Hugging Face 下載報 `WinError 1314`（不能建符號連結，沒開開發人員模式）：先 `set HF_HUB_DISABLE_SYMLINKS=1` 再下載。
- 系統沒有 Python 3.12（只有 Desktop 的 3.13）：`uv python install 3.12`＋`uv venv --python 3.12` 建語音環境，不要拿 3.13 硬裝 3.12 的鎖定清單。
