# 01 總覽與架構

## 目標

- 每月 5–10 支、每支 1–3 分鐘的原創短片；固定角色放在 `output/角色/`，頻道設定與角色規則寫在 `output/AGENTS.md`。
- 16:9 橫式、24fps，社群（Facebook／Instagram）與 YouTube 都發；封面與上架資訊（`發布資訊.md`）是正式步驟。片尾預設不加，AI 生成標示寫在 YouTube 說明欄與社群貼文裡（見 [02](02_端到端流程.md) §12）。之後要做直式短影音不裁切成品，而是用 9:16 重新生成。
- 核心是**可重複的製作管線**：換劇本、換角色，同一套流程照樣跑。

## 三層架構

```
┌─ 知識層：讓人和 AI agent 都知道「怎麼做、為什麼」─────────────┐
│ AGENTS.md（CLAUDE.md 橋接）＋handoff.md：agent 入口與交接        │
│ docs/：已驗證的做法、規則與踩坑；決策歷史在 Obsidian／git log    │
│ output/AGENTS.md：做片規則、退件理由（跨電腦同步，不靠記憶）      │
│ 技能：short-film（開新片、訪談、編劇、預演、製作、自審）     │
│ 角色資產卡：定妝照、轉面圖、表情表、鎖定提示詞、聲音             │
└─────────────────────────────────────────────────────────────────┘
┌─ 全域工具層 <repo>\tools：所有片、所有 agent 共用 ────────────┐
│ h3_shot.py、img25.py、voxcpm_batch.py、tts_lexicon.py、stt.py、     │
│ pron_check.py、pron_compare.py、gen_music3.py、upscale_vsr.py、 │
│ noise_scan.py、start_comfy                                      │
└─────────────────────────────────────────────────────────────────┘
┌─ 每片層 output/<類型>/<片名>/：new_film.py 建立，只改 film.json ──┐
│ make_film.py：chars → masters → frames → voices → inserts → h3  │
│ → amb → edl → music → ending → cut → review（已完成的會跳過）  │
│ 三個人工關卡：首幀總覽、H3 抽格、完整成片                       │
└─────────────────────────────────────────────────────────────────┘
```

### 為什麼這樣分

- **工具層穩定、每片層可拋**：工具改一次全部受益；每支片只有一份 `film.json`（角色、場景、每一鏡、台詞、配樂），`make_film.py` 不用改。
- **知識層是重點**：AI agent 每次對話都是新的。把「使用者退件過什麼、為什麼」寫成檔案，下一個 agent 才不會重犯。這個專案超過一半的品質提升來自這一層，不是換模型。

## 工具選擇

| 環節 | 用什麼 | 為什麼不用別的 |
|---|---|---|
| 首幀 | OpenAI Image 2.5（雲端，medium 畫質） | 本機 Qwen-Image 2.1 2K／50 步畫質沒差，但光線氛圍偏白日光、雙人鏡角色不太像 |
| 影片＋音效 | MiniMax H3 Ref2VA 剪枝 int8（本機 ComfyUI） | 有聲影片＋對嘴＋首尾幀一次出；雲端 Seedance 品質相近但每秒要錢 |
| 加速 | DMAD 4 步蒸餾 LoRA＋comfy kitchen INT8 注意力 | 8 類鏡頭並排看不出差、快約一半；EasyCache 會讓近景糊 |
| 配音 | **VoxCPM2** 設計角色參考音（一次）→ 念所有台詞＋自動挑選；念錯的詞靠讀音替換表 `tts-lexicon.md` 改字 | 2026-10-14 起用 VoxCPM2：官方不限平台（桌機、RTX Spark 筆電同一套）、Apache-2.0 可商用。代價是台灣腔較差（上游實測腔調分數 0.80）、不能標注音。Edge-TTS 只當聲調對照「答案卷」 |
| 挑音 | faster-whisper ASR＋自製聲調比對 | ASR 只驗字，抓不到聲調錯 |
| 配樂 | MiniMax Music 3（純器樂） | YuE2 會夾人聲，且非商用 |
| 放大 | NVIDIA RTX VSR（近景）、FlashVSR（全景） | SeedVR2、SoL-Refiner 會改臉、改嘴型 |
| 空間 | Blender 方塊人布置圖 | 不鎖空間，Image 2.5 會讓學生背對黑板、窗戶換邊 |
| 協作 | Claude Code（Codex 等也可接手）＋AGENTS.md＋專案技能 | 只靠 agent 記憶：每台電腦各一份、不同步，見 [05](05_agent協作與知識庫.md) |

## 不做的事（以及原因）

- **不用 Avatar 平台**（HeyGen 等）：只能做主播式講話，演不了戲。
- **不讓 H3 寫字**：中文會變亂碼，標題、名片一律後製。
- **不做全身舞蹈遠景**：768p 時臉只有幾十像素，放大救不回。
- **不用遮罩擦過去做變身**：要用光流變形或 H3 首尾幀連續變化，觀眾要看到「變的過程」。
