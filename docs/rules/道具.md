# 道具

做法與範例見 [../07_角色與首幀.md](../07_角色與首幀.md) §6。

- 持續出現的道具（耳機、麥克風、眼鏡、蠟板、樂器）要有參考圖：多角度總覽＋細部特寫，放 `output/道具/<道具>/`（`README.md` 鎖外觀描述、記哪幾支片用過），每支片沿用；生首幀時附上，近景附細部、中景以上附總覽，數量不夠時角色定妝優先。（只寫文字，每張首幀的道具都有一點不一樣）
- 做片時直接讀 `output/道具/<道具>/` 的參考圖，不複製到片子資料夾，也不在片內另外生道具圖；場景母版（例：錄音室空景）裡有這個道具時，母版也附它的總覽當參考。（另外生或從母版裁出來的道具圖會跟參考圖對不上，例：母版畫成捲線）
- 道具參考圖先生總覽、確認後再拿總覽當參考生細部；外觀描述寫死實心或鏤空、出線位置、誰接在誰上面、實際高度。（分開生會各畫各的；不寫高度會被畫矮）
- 參考圖只錯一兩處就拿那張編輯（「只改這幾件事」），不整張重生。（重生時零件會互換）
- 同一個道具出現在好幾鏡，每鏡首幀寫死大小：量已認可那幾鏡佔畫面寬幾成、是肩寬幾倍，寫實際尺寸＋「跟肩膀一樣寬、不要更寬」這種上限；拿著的鏡頭寫哪一面朝鏡頭。（只寫 large 會越生越小，寫「手肘到手肘」又太大）
- 桌上的紙張每鏡寫同一句「幾張、實際尺寸與長寬比、擺放方向、約肩寬幾成」，約束寫大小形狀全程不變。（只寫 blank paper 會一鏡一個樣）
- 同一場景的固定道具（墨水瓶、羽毛筆、燭台、書堆）每鏡首幀都寫在哪裡、多大；改一鏡的 frame 時拿其他已認可的鏡對一遍道具清單。（漏寫的那鏡道具就會不見）
- 合上的書寫明書脊在哪一側、「書口那側和兩端看得到米色書頁夾在封面之間」、not a box；最穩是讓書疊被畫框切掉一半，要換姿勢就拿已認可首幀局部修。（會畫成四面是皮的方塊）
- 拿在手上的細長道具（算籌、筆、卷軸）寫「露出拳頭外的長度」跟手比、握哪一端、not a short stub。（只寫公分數會畫成短短一截）
- 同一畫面兩色的同類道具（紅黑算籌、黑白棋子），首幀與約束都寫「每一根從頭到尾都是某色、兩色不混」。（握住處上下兩段常畫成不同顏色）
- 斜伸進畫面的細長道具（木棍、教鞭）每次修完放大看是不是一直線；彎了回到還直的那版當底圖，講解已畫好的圖改成道具放桌上、用手指。（拿修過的圖再修越修越彎）
- 沿尺畫線：首幀筆尖就貼著尺緣，落在紙上、抵著尺靠角色身體那條長邊、離尺端約一掌；從正前方拍寫 THE NIB TIP IS HIDDEN BEHIND THE RULER；action 寫全程貼尺緣滑動。（首幀離尺一點點，H3 就整條畫在尺外）
- 畫的面（紙、沙盤）看得清楚時不在鏡頭前畫新線：鏡頭平視看不到畫的面，或首幀就把圖畫好、人指著講；沙上的圖寫「用棍子刻出的溝，約一指寬、兩邊有推起的沙」。（線跟不上筆尖、畫出來的線沒意義）
- 麥克風線在近景首幀寫「從麥克風底部垂直往下、直到畫面下緣都不碰桿子」；全身鏡寫線夾在架子上的固定點、那個點不會滑動。（只寫「到桿子下段才靠上去」近景會畫成弧線；不寫固定點 H3 會讓接點往下滑）
- 手擋住道具某一段（例：按著耳機時擋住耳機線）而動作會把那段露出來的鏡，用尾幀畫出露出來的樣子。（H3 自己補畫被擋住的那段，會畫成兩條線）
- 動作會改變道具外觀的鏡（拿下耳機、脫帽）一定要給「動作完成後」的尾幀；尾幀裡線或繩照物理寫（例：耳機拿在胸前，線從右耳罩出來搭在右手腕外側、再自然落地）。（只給首幀會溶接或冒出第二副；線的走法不合理 H3 就讓線穿過手臂）
