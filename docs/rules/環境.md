# 環境

## ComfyUI

- 桌機用 Comfy Desktop 的 ComfyUI（`configs\profile.cmd` 自動偵測），連接、背景啟動、模型位置照全域技能 `comfyui`；不要另外在 `%AI_ROOT%\H3` 裝一份。
- 跑本專案前先關掉 Desktop 視窗，由 `tools\start_comfy.cmd` 在背景啟動，才會帶上 `--reserve-vram 1.5`。Desktop 自動更新後先跑 `setup/check_env.py`（只讀）再跑 `smoke_test.py`，補裝的套件或 FlashVSR 節點不見了就照 `AGENT_SETUP.md` §2a 重裝。
- 工具讀寫 ComfyUI 的 input／output 一律經 `tools/comfy_paths.py`，不寫死 `COMFY_DIR\input`／`output`。（Desktop 放在 `ComfyUI-Shared`）
- ComfyUI SaveVideo 只有約 3 Mbps：存 PNG 影格自己用 CRF 12 編碼（`h3_shot.py` 已處理）。

## 工具與路徑

- 工具一律直接跑 repo 的 `tools/`（入口腳本預設就找它），不再複製到 `C:\AI\tools`；要改位置才設 `AI_TOOLS`。新寫的腳本找工具用相對 repo 的路徑。
- 工具要呼叫 venv 裡套件的命令列（例如 edge-tts）時用 `[sys.executable, "-m", <模組>]`，不靠 PATH 找執行檔。（PATH 上可能是系統 Python 的舊版）
- agent 寫批次腳本、在 Git Bash 改檔的約定在 `AGENTS.md`〈工作約定〉。

## Windows 小坑

- ffmpeg 開中文路徑報 `Illegal byte sequence`：把 `cwd` 切進該資料夾、只給檔名。
- ffmpeg 9 不支援 `-filter_complex_script`，改 `-/filter_complex`。
- Git Bash 裡 ffmpeg `drawtext` 會當掉（fontconfig）；要加字改用 ASS 字幕或 PIL。drawtext 字型路徑的冒號要跳脫：`C\\:/Windows/Fonts/...`。
- cmd 的 `set X=1 && …` 會把空白存進變數：寫成 `set "X=1" && …`。
- `cmd /c "call configs\profile.cmd && %PY_H3% …"` 的變數在 profile 執行前就展開成空字串：改用 `cmd /v:on` 與 `!PY_H3!`。
- `yt-dlp` 報 403：`python -m pip install -U "yt-dlp[default]"`、加 `--js-runtimes node`；`--download-sections` 常 403，改下載整支再用 ffmpeg 切。
- faster-whisper 缺 cuBLAS DLL：把 venv 裡 `nvidia/*/bin` 加進 DLL 路徑（`stt.py` 的 `_add_cuda_dll_dirs()`）。
- 標楷體用 `kaiu.ttf`；`mingliub.ttc` 是 ExtB 字集，一般字會變方塊。
- Hugging Face 下載報 `WinError 1314`：先 `set HF_HUB_DISABLE_SYMLINKS=1`。
- 系統沒有 Python 3.12：`uv python install 3.12`＋`uv venv --python 3.12` 建語音環境。
