# 構圖與角色

## 生圖後端

- 預設 OpenAI 生圖（`gen_image.py` 的 `IMAGE_BACKEND=auto`）：Codex CLI 優先（扣 ChatGPT 訂閱），不能用才走 Image 2.5 API；選定的後端失敗就停下，不改試另一個、不自動改用千問。本機 Qwen 是備選，要用就整支片設 `IMAGE_BACKEND=local`。
- 金鑰由使用者自己設定（`OPENAI_API_KEY`／`OPENAI_KEY_FILE`／`~/.openai.env`），agent 不經手、不讀出內容、不寫進 repo。
- 生圖一律經範本（`make_film.py`／`make_studio.py`）或 `gen_image.py`，不要手動用 `draw` 代替。（不會記到 `work/image_backends.json`，片尾與發布資訊的工具名稱會錯）
- `run_demo.py`、`smoke_test.py` 固定 `--backend local`（驗證本機安裝用）。
- 生圖被安全系統擋（例："despair" 之類措辭）就換說法。

## 空間與構圖

- 不同視角的首幀從同一張底圖編輯；首尾幀也從同一張圖改。（換機位後背景會跑掉）
- 布置圖當生圖參考，提示詞寫「只抄機位與站位，不抄方塊外觀」。
- 教室方位固定：黑板在前、學生面向黑板、窗在學生左手邊。（自由構圖曾讓學生背對黑板）
- 主角腰上或更近（臉佔畫高 10% 以上）。（768p 全景臉糊，放大救不回）
- 不讓人物橫向走，改原地轉身。（H3 會跟拍，桌椅跟著滑）
- 空景、時鐘、桌面特寫用靜圖＋慢推。（H3 會自己加人或切走）
- 單人鏡提示詞完全不提其他人；多人鏡寫 `Exactly N people`。（提到誰誰就會冒出來）
- 提示詞必寫 `NO black letterbox bars`。（電影感提示詞會自帶黑邊）
- 桌上有要維持大小的道具時不用低角度，用跟其他鏡同高的平視或「鏡頭略俯」。（低角度把平放的東西拍成寬扁長條）
- 坐著的人不要入鏡到腳，畫面下緣切在桌面下方。（生圖常把小腿拉長，換 seed 也改不掉）
- 港口、街道、廣場這類平常有人的地方，空景不留可站人的地面：從海上看出去、城市只在遠方地平線。（H3 幾秒後就在空地長出人和貨物，約束擋不住）
- 近景背後貼牆、門、櫃子或拉上的窗簾，不留空地、門口、走廊或窗內房間。（H3 會讓路人走進空地）
- 影子打在人身上不是一條直線，也不跟背景布幕上的影子連成一片；要影子就只放在背景上。（人是立體的、又站在布幕前方）
- 首幀底部缺畫面時用生圖重畫，不用邊緣複製補。（H3 會長成鞋底黑條）

## 角色定妝與一致性

- 每個角色一組：轉面圖（正、3/4、側、背）、6 格表情表、臉部近照（正面＋3/4）、鎖定外觀描述，放 `output/角色/<角色>/`；每次照抄 `README.md` 的鎖定描述，不自己重寫外觀。
- 首幀依景別每個角色附 1–3 張定妝（每鏡 `sheets`）：全身鏡不附近照、特寫鏡附近照、雙人鏡每人少附；提示詞寫明不要照抄格子版面。（參考圖越多每人比重越被稀釋）
- 本機 Qwen 生圖的參考圖只能是單張半身照，並用 Qwen-Image-Edit，不要用 Qwen-Image 2.1 附參考圖。（Qwen 會把多格版面照抄成拼貼；2.1 會鎖死成參考圖的正面姿勢）
- 每一鏡的首幀提示詞都照抄角色完整外觀描述。
- 只改角色毛色或服色：拿已認可的轉面圖直接編輯改色，不從文字重生。（重生會連形狀與姿勢一起變）
- 小孩要明顯是 11–12 歲（寫 childish face, never a teenager）。
- 頭套寫素色、無條紋、無斑點、無鬃毛、布偶繡眼，並加「a lifeless prop whose sewn face and eyes never move」。（不寫會變老虎；H3 會讓道具眨眼）
- 動物角色用真動物比例、後腳站立，不穿人的衣服；裸身動物用深色長毛，寫明長毛蓋住肚子與兩腿之間。（擬人版太像人；淺色毛私密部位太明顯）
- 寫字的人一律右手拿筆：首幀直接畫成已經在寫、寫明右手在畫面哪一側（面對鏡頭時在畫面左側），約束加「全程右手拿筆、不換手」；不寫跨過身體的動作。（生圖會乾脆換成左手）
- 換角重製的首幀寫死大小與位置：頭頂跟原本的人一樣高、腳在原本腳的位置、前肢照抄手臂位置。（不寫時角色比人大，骨架對不上）
- 角色參考音在定裝時跟定妝圖一起做，定案存 `output/角色/<角色>/ref_<代號>.wav`，之後每支片沿用、不重新設計。（聲音才不會在片與片之間漂移）
