# 做片規則

所有影片類型共用的做片規則。每條是一句做法，括號裡是一行理由；實測數字與退件經過放在作者的 Obsidian 筆記，不放這裡。

## 規則放哪裡

| 層 | 位置 | 放什麼 |
|---|---|---|
| 專案 | `AGENTS.md` | 授權、環境、安全、資料夾結構、規則索引 |
| 通用做片規則 | `docs/rules/`（本資料夾） | 所有類型都適用的做法 |
| 類型規則 | `kinds/<類型>/rules.md` | 只屬於某類影片的規則（只寫跟通用規則不同或額外的） |
| 頻道規則 | `output/AGENTS.md`（不進 git） | 頻道名稱、角色禁則、工作習慣 |

同一條規則只寫在一個地方；其他文件（技能、範本 README、`docs/02` 流程）需要時連到這裡，不再抄一遍。範本程式的預設值要跟規則一致（例：H3 步數由 `tools/h3_steps.py` 統一判斷）。

## 新增規則

- 退件或實測得到的經驗寫成一句祈使句加一行理由，放進對應的檔案；只屬於某類影片的寫 `kinds/<類型>/rules.md`。
- 跟既有規則衝突時，改掉舊的那條，不要兩條並存；拿不準的先問使用者。
- 實測數字、退件經過、日期寫在作者的筆記（或 `git log` 的 commit 訊息），這裡只留結論。
- 寫回時不放個人資訊（本 repo 公開）。
