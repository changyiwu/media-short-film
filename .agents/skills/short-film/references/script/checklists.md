# 短劇審閱與修改清單

## 輸出格式

每個問題固定四段，依**影響程度**排序：

1. **問題**：具體指出失效之處。
   - **依據**：對應的場次、節拍或臺詞。
   - **影響**：為何妨礙理解、情緒或節奏。
   - **修改**：可執行的修正方向。

最後列「**建議保留**」——只列真正有效、修改時應該保住的元素。不要用空泛稱讚取代診斷。

---

## 題材與觀眾

- [ ] 題材、核心前提與目標觀眾清楚且彼此相符。
- [ ] 類型承諾在**前 15 秒**就能被觀眾辨識。
- [ ] 有**主題錨點**（觀眾要帶走的一句話），每一場都回扣得到；回扣不到的場刪掉或改寫。
- [ ] 原創短劇：寫得出用了哪個引擎（地位／資訊／身分／形象差）與模式（`drama-hooks.md`）。

## 結構與節奏

- [ ] 有明確的鉤子、推進、反轉、收尾，各節拍秒數對得上目標長度。
- [ ] 沒有重複或停滯段落——1–2 分鐘的篇幅撐不起鋪陳。
- [ ] 單支獨立成篇，沒有莫名其妙的「下集待續」。

## 角色動機與連貫性

- [ ] 主角的行為符合角色設定檔（`films/角色/<角色>/README.md`）的個性，沒有為了劇情硬改。
- [ ] 角色的選擇由已建立的目標、壓力或新事件支撐。
- [ ] 角色轉變有連續的可見行動與代價。

## 場次與衝突

- [ ] 每場有角色目標與阻力，並改變資訊、關係、目標、風險或情緒之一。
- [ ] 衝突隨場次推進而升級，不只由角色說明。
- [ ] 場與場之間是「因為…所以」；寫成「然後」的接縫都補了原因或刪掉。

## 臺詞與潛臺詞

- [ ] 臺詞符合角色關係與當下目的，不是解說背景。
- [ ] 關鍵資訊盡量由行動、反應、迴避或試探承載。
- [ ] 主角的臺詞夠短。
- [ ] 轉折與隱喻有一句台詞或一個畫面講白；梗一聽就懂。
- [ ] 台詞和前後畫面對得上：提到的動作先演出來、數量一致、「他／她」指誰看得出來、反應緊接動作。
- [ ] 台詞總字數對得上該場秒數（**VoxCPM2 實測約每秒 3.5 字**；`tools/table_read.py` 會算）。
- [ ] **台詞密度撐得起片長**：台詞總秒數 ÷ 片長 ≥ 20%。低於這個數字通常是戲太稀、在靠氣氛硬撐——而每一秒空鏡都要付生成費。

## 反轉與收尾

- [ ] 反轉有前文線索，回看時合乎人物與因果；被哪一句台詞或哪一個畫面翻掉寫得出來，反轉後留一拍反應。
- [ ] 收尾帶來餘味、新問題或不可逆代價，不是單純中斷事件。

## 技術可行性（本機 MiniMax H3）

> 這一區不通過就要**改劇本**，不能留給後製。

- [ ] 沒有快打、追逐、劇烈晃動的鏡頭（H3 遇到快動作容易變形）；真要打鬥已跟使用者確認。
- [ ] 同一個鏡頭只有一個人說話，對話靠切鏡頭來回。
- [ ] 每個鏡頭能在 12 秒內演完；一句台詞最好不超過 40 字。
- [ ] 沒有只有一個字的台詞（改成兩三個字）。
- [ ] 畫面上不需要讀得懂的文字；需要的已註明後製疊字。
- [ ] 場景數在創作簡報的上限內，沒有偷加。
- [ ] 有台詞的新角色數量克制——每個都要多做一組參考圖和一個聲音。
- [ ] 道具物理合理（不憑空出現或消失、數量寫清楚）；數數的台詞，畫面沒有可以數的東西。
- [ ] 每鏡只放要演戲的人。
- [ ] 天馬行空放在**設定與情境**的奇特，不是動作場面。

## 16:9 構圖語言

- [ ] 有用到寬景或環境敘事，沒有浪費橫式的空間。
- [ ] 特寫克制，中景與中特寫是主力。
- [ ] 沒有出現「角色塞滿畫面」這種直式構圖邏輯。
- [ ] 沒有寫鏡號、景別代號、運鏡或影片模型參數。

## 格式與最終修改

- [ ] 場次標頭皆含場次、內景／外景、地點、時間，地點名稱跨場一致。
- [ ] 短片標題、角色名稱、臺詞與畫面文字格式一致；主角名稱全片一致（以角色設定檔為準）。
- [ ] 修改優先處理妨礙理解、情緒或節奏的問題，並保留有效元素。

## 鏡表（若已進到第 9 階段）

- [ ] 每鏡 4–12 秒；有台詞的鏡頭秒數夠念完（每秒約 3.5 字）再留反應時間。
- [ ] 一鏡最多一句台詞、一個人說話。
- [ ] 沒有切在台詞中間、連續動作中間或反轉揭露的瞬間。
- [ ] 每鏡都寫了場景／景別、畫面裡的角色、首幀畫面、動作；同場景的景別與窗戶方向一致。
- [ ] 「畫面裡的角色」只列真的入鏡演戲的人，並註明單人或必須同框。
- [ ] 運鏡欄預設靜止；寫了運鏡的鏡頭，動作描述沒有跟它矛盾。
- [ ] 沒台詞的鏡頭寫明「不說話」。
