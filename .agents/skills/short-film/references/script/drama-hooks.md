# 戲劇鉤子：AI 短片抓馬梗的上位模式

> 移植自上游 `agent/skills/shanshiba-drama/references/drama-hooks.md`（2026-10-11 整理，2026-10-23 版），移除上游頻道的示範與頻道專屬招式，結尾改成本專案「單支獨立成篇」的寫法。
> 上游整理的來源：微短劇編劇方法文（知乎、搜狐、人人都是產品經理、遠見）、AI 貓狗短劇產業分析（21 世紀經濟報導）、海外 microdrama 分析（Rappler、BuzzFeed）、AI 影片趨勢整理（Versely 等），網址見文末。**多為業界經驗分享，不是學術定論**；下面的分類是整理後的歸納。
> **適用範圍**：原創短劇、換角重製改台詞。數學故事、其他講史實的片**不要套**——為了抓馬加的衝突與反轉多半是史料沒記載的事（見 `output/數學故事/AGENTS.md`）。

## 一、所有抓馬的共同引擎（四種「差」）

每一個爆款梗，拆到最底層都是製造落差：

| 引擎 | 意思 | 觀眾的感受 |
|:--|:--|:--|
| **地位差** | 誰壓誰，然後上下顛倒 | 憋屈 → 爽 |
| **資訊差** | 有人知道、有人不知道（觀眾常常先知道） | 緊張、等著看好戲 |
| **身分差** | 看起來是 A，其實是 B | 震驚、「原來如此」 |
| **形象差** | 外表和行為不搭（可愛的臉講狠話） | 好笑、上頭 |

**情緒公式：先壓（委屈、羞辱、被看不起）→ 再爆（反轉、打臉、揭露）→ 不給滿足就切斷（卡點）。**
微短劇業界叫「爽點」：觀眾在那一刻得到的情緒回報。

## 二、20 個上位抓馬模式（可套任何主題）

> 每個模式都寫：**骨架**（抽象寫法）／**短劇常見樣子**／**換成任何主題的套法**。

### A. 身分與地位類

**1. 隱藏身分（扮豬吃老虎）**
- 骨架：最不起眼的人，其實是最高層級的那個。
- 短劇：億萬富翁裝窮、被嫌棄的女婿其實是大佬、實習生其實是董事長。
- 套法：找出這個主題裡「最被看不起的角色」和「最高的頭銜」，把兩個疊在同一個人身上。

**2. 身分揭露的那一刻（掉馬甲）**
- 骨架：一句話、一張卡、一個動作，讓全場知道他是誰。
- 短劇：「總裁突然出現喊她老闆」、亮出證件、一通電話「董事長您好」。
- 套法：設計一個**可視化的身分證明**（名牌、證書、徽章、一句稱呼），在最低點亮出來。證件上的字一律後製疊字（`overlay`）。

**3. 地位顛倒（跪下梗）**
- 骨架：前半段 A 逼 B 低頭，後半段 A 對 B 低頭。
- 短劇：反派要主角跪下，身分曝光後反派自己跪地求饒。
- 套法：同一個動作做兩次，**施受者對調**（前面誰要誰道歉、後面就換人道歉）。

**4. 一句話擺架子（你知道我是誰嗎）**
- 骨架：配角用頭銜壓人，主角輕描淡寫回一句，頭銜瞬間失效。
- 套法：讓配角炫耀一個這個領域的「等級名稱」，主角的等級剛好高一階或完全不同維度。

**5. 被拋棄 → 對方後悔（退婚／火葬場）**
- 骨架：一開始被拒絕、被開除、被刷掉，之後對方發現錯過了寶。
- 短劇：退婚、被趕出家門、被公司開除，三年後回來。
- 套法：「當初誰沒選你」＋「現在你成了他要求的人」。

**6. 團寵／一群大佬撐腰**
- 骨架：主角一出事，好幾個強者同時出場護他。
- 短劇：「五個大佬哥哥」、各路高手都是主角的人。
- 套法：把這個主題裡的各種「派系代表」都變成主角的靠山，同時現身（多人同框，H3 先測最難那一鏡）。

### B. 資訊與真相類

**7. 觀眾先知道（資訊差）**
- 骨架：觀眾知道祕密，角色不知道，等著看他怎麼踩雷。
- 業界說法：卡點前先製造「觀眾知道、角色不知道」的落差最有效。
- 套法：開頭就讓觀眾看到真相，接著讓角色在不知情的狀況下講出會被打臉的話。

**8. 當眾公審（拿出證據）**
- 骨架：在最多人看的場合，攤出一個無法反駁的證據。
- 短劇：宴會、婚禮、董事會、家族聚餐；甩出錄音、合約、DNA。
- 套法：選這個主題裡**最公開的場合**（會議、典禮、群組）＋**最有公信力的文件**。

**9. 真假錯認（真假千金）**
- 骨架：兩個人身分被調包，錯的那個享受一切，對的那個被嫌棄。
- 近年流行**反套路**：真千金不吵不鬧、自己變強，反而是另一種打臉。
- 套法：兩個看起來很像的東西／人，被大家認錯；揭曉時所有人的態度瞬間翻面。

**10. 背叛與偏心**
- 骨架：最親近的人站錯邊。
- 短劇：丈夫外遇閨蜜、父母偏心、綠茶表面無辜。
- 套法：主角的「自己人」在關鍵時刻選擇了對手（之後一定要回收：後悔或被揭穿）。

### C. 規則外掛類

**11. 重來一次（重生／回到過去）**
- 骨架：帶著未來的記憶，回到出事前的那一刻。
- 套法：「如果我早知道……」→ 讓主角回到某個關鍵日子，每個選擇都做對，旁人看不懂。

**12. 系統／面板（外掛）**
- 骨架：主角突然看得到別人看不到的規則、數值、任務提示。
- 短劇：「叮！系統啟動」「完成任務獎勵○○」。
- 套法：把這個主題裡**真實存在的數字**（分數、時數、等級、KPI）變成只有主角看得到的遊戲面板（面板＝後製疊字）。

**13. 倒數與限時賭注**
- 骨架：有個時間或數量的期限，不達成就完蛋。
- 套法：用這個主題裡真的有的期限（截止日、考試、評鑑）做倒數字卡。

**14. 誇張數字**
- 骨架：數字大到不合理，用來一秒建立賭注。
- 短劇：億元支票甩臉、十倍奉還、千萬違約金。
- 套法：把這個主題的小數字放大成史詩級（「一百小時」「全國第一」）。

### D. 形象反差類（AI 短片特別吃這套）

**15. 可愛外表 × 成人劇情（擬人反差）**
- AI 貓狗劇：貓扮貴妃甩小宮女巴掌、講宮鬥台詞；柯基演美劇；胖橘系列連載百集。
- 骨架：用最萌、最無害的外型，演最狗血、最權謀的戲。
- 套法：選這個主題裡**最不像會吵架的角色**，讓他們上演宮鬥。

**16. 錯置場景（動物上班）**
- AI 貓狗劇：貓送外賣、擠地鐵、打工。
- 骨架：把角色丟進不屬於他的場景，照樣認真做事。
- 套法：把 A 領域的人放進 B 領域的規則裡（例：用武俠的方式開會）。

**17. 荒謬混種（brainrot）**
- 例：義大利 brainrot（咖啡杯頭的芭蕾舞者）、水果出軌劇（fruit slop）。
- 骨架：兩個不該結合的東西硬結合，再認真給它一個身世和劇情。
- 套法：把這個主題的兩個名詞拼成一個角色，並給他一句招牌台詞。

**18. 是真的嗎？（double take）**
- 例：AI 假街訪、像真的但有一點怪。
- 骨架：一開始看起來完全正常，細節越看越不對。
- 套法：先拍得很寫實，再慢慢放一個「只有仔細看才發現」的破綻。

### E. 結構與收尾類

**19. 戛然而止（卡點）**
- 骨架：在揭曉的前一格切黑，而不是在解決之後。
- 業界：卡點要落在主線、停在「即將爆發」的瞬間；要具體到某一句台詞或動作，不能只寫「留下懸念」。
- 海外分析（Rappler）：microdrama 等於**把懸念變成收費點**——反派要垮台、女主亮出證據的那一秒，畫面變黑。
- 本專案單支獨立成篇：卡點只能用在「答案觀眾自己想得到」的地方，不能把主線的答案藏到不存在的下一集。

**20. 反套路（觀眾以為會這樣，結果再翻一層）**
- 骨架：先照套路走，讓觀眾猜到下一步，然後拒絕給那一步。
- 套法：用前 19 招其中一招鋪好，最後一秒改走另一招。

## 三、節奏公式（短片長度通用）

| 時間 | 要做的事 |
|:--|:--|
| **0–3 秒** | 衝突或反常畫面直接出場（被羞辱、東西被甩到臉上、奇怪的組合） |
| **3–10 秒** | 交代人物關係：誰壓誰、賭注是什麼 |
| **中段** | 主角受壓，情緒累積（委屈越深，後面越爽） |
| **中後段** | 反轉：身分、實力或真相揭露 |
| **結尾** | 爽點爆發 → 留一個問題或餘味（單支片不寫「下集待續」） |

- 業界經驗值：每 30 秒一個鉤子；每 2 分鐘至少一個。
- 單支只推進**一件事**。

## 四、AI 短片常見的視聽語言（拍法）

| 拍法 | 本機 H3 能不能做 |
|:--|:--|
| **甩東西到臉上**（文件、支票、考卷）＝衝突開場的標準畫面 | 快動作容易糊：改成「遞出／拍在桌上」＋特寫反應，或首尾幀鎖住結果 |
| **全場倒抽一口氣**：一排人同時轉頭、張嘴、杯子掉地 | 群眾同步動作要寫清楚人數與方向，最難那一鏡先測 |
| **鏡頭推近眼神**＋眼神由卑微變冷：「她不裝了」的瞬間 | 慢推可以；表情變化照 `action` 官方結構寫具體（眉、嘴角、視線） |
| **身分字卡**：人物定格＋大字頭銜 | 一律後製疊字或插入鏡（`overlay`、`insert`） |
| **慢動作走進來**：靠山登場 | 不要讓角色橫向走（H3 會跟拍）；改朝鏡頭走近或原地轉身 |
| **悲傷流行歌**配上動物或物品的劇情 | 配樂用 Music 3 純器樂；要人聲歌要另外處理 |
| **跪地、鞠躬、手抖的特寫**：地位反轉的畫面證據 | 可以；跪地等全身動作首幀畫動作開始前、留頭頂空間 |
| **切黑＋「未完待續」**：卡點 | 單支片不用「未完待續」；切黑＋停在一句台詞可以 |

## 五、套用檢查表（寫任何主題前先問）

1. 這個主題裡，**誰最被看不起？誰的頭銜最高？**（→ 隱藏身分）
2. 這個主題有哪些**等級、證書、稱號、數字**？（→ 掉馬甲道具、系統面板、誇張數字）
3. **最公開的場合**是哪裡？（→ 當眾公審）
4. 有沒有**兩樣容易被搞混**的東西？（→ 真假錯認）
5. 有沒有一個**真實的期限**？（→ 倒數）
6. 誰是**最不像會吵架**的角色？（→ 萌外表演宮鬥）
7. 開頭 3 秒的**反常畫面**是什麼？
8. 最後一秒停在**哪一句台詞**？

## 六、怎麼用在一支片

- 需求訪談後、題材階段（`workflow.md` 階段 2）先跑第五節的檢查表，挑 1–2 個模式就好；一支 1–3 分鐘的片疊太多招會看不懂。
- 交付核心概念時寫明「用了哪個引擎＋哪個模式」，以及**被哪一句台詞或哪一個畫面翻掉**。
- 反轉之後立刻用畫面兌現（反應、後果），不要靠台詞解釋笑點。
