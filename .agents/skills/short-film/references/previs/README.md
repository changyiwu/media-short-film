# 預演（選用）：Blender 鎖空間與運鏡

> 原 `blender-previs` 技能，2026-10-15 併入 `short-film`。需求訪談、`film.json` 填寫規則、自審清單已搬到 `short-film` 主流程（`../interview.md`、`../film-json.md`、`../review.md`），本資料夾只留 Blender 專用的部分。

## 這一步解什麼問題

AI 影片最常見的失敗是**空間隨機性**：座位跑掉、人物增生、背景冒出多餘物件、左右換位、道具位置漂移。做法是**先用 3D 鎖空間與運鏡，再交給影片模型生成**。

**界線（不可含糊）**：預演**只解空間與運鏡**，**不解決對嘴**；布置圖通過不等於對嘴或表演通過。

**什麼時候做**：多人同框、座位或左右位置容易跑掉、要運鏡、同一場景很多機位。單人、固定鏡頭的短片跳過，直接填 `film.json`。

## 開工前

1. 需求確認表與鏡表已經使用者確認（`../interview.md`、`../script/segmentation.md`）。
2. 該片 `output/<類型>/<片名>/製作紀錄.md`；角色外觀讀 `output/角色/<角色>/README.md`。
3. Blender 安裝見 `<repo>/docs/06_安裝.md` §6b（安裝版、5.1 以上）；**操作方式一律照全域技能 `blender`**，本資料夾的專用規則見 `blender-rules.md`〈前置〉。

## 規則

- **生成之前先看畫面**：每鏡先算布置圖，再花 GPU。布置圖成本趨近於零（13 鏡 0.8 秒）。
- **一鏡一機位要說清楚**：不同鏡號共用同一機位時要明講，不要讓鏡數看起來比實際畫面豐富。
- **運鏡與描述不可矛盾**：標了 locked 就不寫推進；想推進就必須真的做成 keyframe。
- **收件要鎖節點**：只取指定的 Save 節點輸出，不要遍歷所有輸出而誤收輸入素材。

## 交出

鏡位契約（`output/<類型>/<片名>/work/blender/camera_plan_v<N>.json`）→ 場景與布置圖 →（必要時）運鏡 → 檢查結果。接著回主流程第 5 步，把 `visible`、`motion` 寫進 `film.json`（見 `../film-json.md`）。

**絕不**：改動既有交付版本、覆寫別人正在用的檔案、把未驗收的結果寫成已通過。
