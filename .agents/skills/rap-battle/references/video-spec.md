# 影片規格與鏡表

## 規格

| 項目 | 值 |
|:--|:--|
| 畫面 | **橫式**：H3 1344×768 → 成片 1920×1080、24 fps；手機版 1280×720 約 27 MB |
| 長度 | 3–4 分鐘（兩首歌＋開場＋片尾約 8 秒投票卡） |
| 鏡數 | 50–60 鏡：開場 3–5、A 約 22、換場 3–5、B 約 24、收尾 3–4 |
| 每鏡 | 1–6 秒（跟著歌詞一句一鏡）；H3 每鏡 ≤ 12 秒 |
| 聲音 | −16 LUFS、真峰值 ≤ −1 dBTP；觀眾歡呼墊在攻擊後與片尾 |

## 結構

| 段落 | 內容 |
|:--|:--|
| 開場 | 觀眾視角擂台全景＋片名卡 → DJ 喊開場（名牌）→ A、B 各自上台 → 兩人對峙（VS 卡，靜態慢推） |
| ROUND 1 | A 演唱鏡（第一鏡附名牌）穿插：**閃回／插入鏡**（歌詞講到的事件）、**B 的不屑反應鏡**、**觀眾 B-roll**、雙人同框（A 唱、B 閉嘴）；最後一句殺招用胸上近景 |
| 換場 | 觀眾「喔～」→ DJ 刷碟特寫 → DJ 指向 B（靜態）→ B 捲袖、走到麥克風 |
| ROUND 2 | 同上，換 B 唱、A 反應；B 的殺句後觀眾爆炸 |
| 收尾 | 觀眾歡呼丟紙 → （定論／反轉插入鏡＋DJ 口白）→ 兩人互相點頭或背對賭氣 → DJ 片尾三拍「誰贏了？下一場是誰？你決定！」→ 投票卡 |

## 鏡型

| 類型 | 寫法 |
|:--|:--|
| 演唱鏡 | `kind: "sing"`；腰上（MCU）或胸上（CU），**主角不用全身遠景**（臉會糊）。動作寫**慢而清楚**的手勢：手放胸口、指向對手、數手指、比耳朵聽不到；**不要寫甩手、劈砍、兩手亂揮**（會糊）；加 `calm: true` |
| 反應鏡 | `kind: "silent"`；閉嘴、不屑微笑、翻白眼、抱胸；會自己切鏡的加 `last_first: true` |
| 雙人同框 | `subj` 第一位是唱的人；`cons` 寫「右邊的人全程閉嘴、雙手交叉不動」 |
| 閃回／插入 | 歌詞講到的事件（年代場景）、現代教室；`scene` 指到 `places` 的一個地點；不放麥克風、舞台燈 |
| 觀眾 B-roll | `subj: ["T"]`、全景；同步動作（舉手、跳、丟紙） |
| DJ | 短的正面喊話鏡（`kind: "sing", voice: "dj"`）＋刷碟特寫；長口白放畫外 |
| 靜態 | `still: true`＝首幀慢推（VS 對峙、DJ 指向）；`custom`＝自己做的影片（精準的數學圖解、圖表） |

## at（鏡頭開始時間）

| 寫法 | 意思 |
|:--|:--|
| `0.0` | 秒數（只有第一鏡用） |
| `["A", 3]` | A 第 4 句（從 0 算）開口前 0.12 秒；`["A", -1]`＝A 第一句前 4 秒、`-2`＝前 2.5 秒 |
| `["dj", "switch", -0.3]` | DJ 換場口白開始前 0.3 秒（open／switch／verdict／end） |
| `["mark", "a_stop", 0.3]` | 時間點＋偏移：`a_first`（A 第一句）、`a_stop`（A 收尾拍）、`b_zero`（B 那首的 0 秒）、`b_first`、`b_last`（B 最後一個字）、`music_end` |

每鏡的結束＝下一鏡的開始；兩鏡不能短於 0.8 秒（程式會擋）。

## 首幀規則

- 首幀畫「**動作開始前**」的姿勢，不要畫動作最高點。
- 擂台：左右兩半是兩人的配色，**地板只有金色圓環**（不要星形、符號），**不要旗子、布條、國徽、招牌字**。
- 一人一支麥克風，固定在原位。
- 書、黑板、螢幕上要出現的字寫在 `frame` 裡、用雙引號；其他地方一律不要字。
- 兩位饒舌手和 DJ 的臉型、鬍型、頭飾要一眼分得出來（同一系列也不要撞臉）。
- **插入鏡不套擂台的句子**：`film_look` 提到饒舌手，空景會畫出人；提到舞台地板，插入鏡地上會多一圈漆。插入鏡另寫 `film_look_insert`，`no_text` 裡只屬於擂台的那段放進 `arena_only`（插入鏡會拿掉）。
- **電影鏡頭語言**：演唱特寫用 85mm f/1.4 淺景深，反應鏡可用過肩、插入鏡用特寫，開場用大遠景或低角度；每鏡在 `frame` 寫焦段。要真人感照 `docs/07` §3b（選用）。
- **只拍手的插入鏡要明寫「畫面裡只有手和前臂，不要臉、不要頭、不要其他人」**（上游〈人性之辯〉沒寫，4 張只拍手的插入鏡畫出整個古人）；**插入鏡的道具不要長得像對決的人物**（布偶被畫成兩位主角的 Q 版，等於暗示誰是壞人）。
- 小孩靠近危險（井邊、月台）的畫面會被 OpenAI 安全系統擋 → 改畫「已經被救回來」的結果。
- 名畫（`painting: true` 的鏡）逐張看圖核對，不能只看檔名：Commons 的 `Vincent van Gogh - Starry Night` 其實是 1888〈隆河上的星夜〉。名畫鏡慢推較小，字卡改放左邊。
- **手指要數**：演唱鏡空著的那隻手 Image 2.5 常畫成張開、少一指 → 不是戲的重點就改握拳或手不入鏡，動作也寫不張開；要張開就寫手掌朝鏡頭、五指分開。`finger_sheet.py` 只是輔助（靠邊的手抓不到），每鏡完整首幀張開的手逐隻數。

## H3 規則（範本已寫進 spec）

- 演唱鏡用兩人人聲分軌當固定音軌（`audio.fixed`）對嘴；無聲鏡給靜音，角色才不會自己嘟囔。
- 限制句：一鏡到底、不要旗子／布條／國徽、手的結構正確、不多出人、不出現新字；擂台鏡加「背景一直是擂台」、麥克風不動；`locked` 的鏡加「鏡頭不推近」。
- **H3 會自己切鏡**（常在 0.5–2.4 秒切到別的構圖，有時冒紅旗）：`review` 會抓；用到的範圍內有切鏡就加 `last_first: true`＋`seed_bump` 重拍；兩次都切就改首幀（例如改成胸上近景、姿勢簡單）。
- 手糊掉：改慢動作、`draft: false`（14 步）、抽 2 個 seed 挑清楚的。**搖扇子、揮道具會糊**：道具全程拿穩，動作放在頭和眼神。
- **H3 拍動作時會多長指頭**（上游首幀 5 根、成片第 6 根）→ `finger_sheet.py --clips` 看每鏡 25／50／75% 的手，張開的手逐隻數到 5。
- **不要寫「拿著東西走出畫面」**（上游人捧牌位走出去，H3 讓人變殘影、憑空消失）→ 人留在畫面裡完成動作，限制句寫「stays fully in frame, never walks away, fades or blurs」。
- **嘴不動**：首幀閉嘴又尾幀＝首幀，嘴型會被鎖住；寫「quietly、low voice、stays still」也會讓嘴變小。先用同場已驗證的首幀，action 寫 `his mouth opens visibly on every syllable`、換 seed。
- **尾幀＝首幀會讓插入鏡、人物幾乎不動**：不需要鎖的鏡拿掉 `last_first`，用 14 步重拍；拿掉後要再查切鏡與旗子。拍完跑 `motion_check.py`，動作量最低的幾鏡要看。
- **soundscape／setting 只有觀眾 B-roll 鏡才寫 crowd／cheering**：演唱鏡、反應鏡、DJ 鏡寫了人群聲，H3 會把人畫進背景；近景背後也不要留空曠地面。
- **慢推只准約 5%**（再多會推成大特寫、改臉）；不要用遮罩合成把背景換回首幀（人物邊緣被切到）。
- 背景突然變色（冒綠布、整片變綠）：換 seed 兩次都還是，改尾幀＝首幀＋限制句只寫「背景與顏色全程跟 <Picture 1> 一樣」；**不要寫「不要綠色」**，寫了反而會提醒它。
- 改了 `battle.json` 再跑 `specs`，內容沒變的鏡不會重寫 spec（已做好的鏡不重跑）。

## 字卡與特效（範本自動做）

- 片名卡、VS 卡、三人直排名牌（各出現一次）、講白字卡（`cards`，鏡頭的 `gfx` 指定）、投票卡；字卡會避開臉、不壓字幕和左上 ROUND 角標。
- 字幕：整句、韻腳字用己方顏色、唱到時砸下來；左下說話者色塊；數字用阿拉伯數字、同音字換回原字。
- 攻擊：押回去的那句從唱的人那側射出月牙斬、對手那側爆開（震動＋色差）；近景只在下緣角落爆開，不掃臉；COMBO「押韻！雙押！三押！」、最後一句「殺招！」。
- 長演唱鏡每句交替推近 1.18 倍，推近不切到頭頂（整段找不到臉就不推）；特寫（`dist: "CU"`）不推；只在切進 `flash_scenes` 的閃回時閃白（不要每個插入鏡都閃）。
- 有字卡的鏡不會推近（推近會把字卡裁掉）。
- COMBO 字不疊到別人的鏡頭（下一鏡切到對手就先消失）；下一句是「收」（`atk: false`）時押韻字也先消失；四押以上顯示國字（四押！五押！）。
- DJ 長句照標點拆段、太長再照逗號拆（每段 ≤ 17 字，字才不會縮小）；有 `dj_align.json` 就照實際念到的字出，短句至少留 0.8 秒。
- 片尾大字 4 行時收緊，第 4 行不碰投票卡；`end_beats` 每行 ≤ 8 字，大字不能壓到 DJ 的臉（K04 首幀讓 DJ 站右三分之一、左半邊留空）。
- `srt` 字幕檔的片尾照 DJ 實際念的 `dj.lines.end`（`end_beats` 只是畫面大字）。
