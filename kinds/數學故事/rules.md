# 數學故事：類型規則

> 通用做片規則在 `docs/rules/`，這裡只放這類影片額外的規則。

## 這類片是什麼

講數學家或數學史的短片，觀眾是學生（課堂播放或自學）。

## 規則

- 情節不偏離史料：說法不一的（例如外號的由來）不當定論講，能拿掉就拿掉；史料沒記載的事（例如他怎麼想到的）不編成史實，需要的話只做明顯的象徵畫面（不放人物）。
- 教材和網路資料都要查：先讀康軒備課 PDF 的對應課本頁與補充資料，再上網查史料，兩邊對照後才訪談、編劇；說法互相矛盾、或找不到第一手出處的，在核對表標「相傳」或不採用。網址寫進核對表與角色 `README.md`。讀備課 PDF 用 `file-toolkit` 技能的環境（pypdfium2），不用 Git Bash 的 `pdftotext`。（中文抽不出來）
- 劇本附「史實與來源核對」表，每一項說法寫依據（課本頁、古代文獻、通論），另列「不是史料、是畫面需要的部分」（人物長相、對白、象徵畫面、現代數字寫法），給使用者核對。
- 人物沒有留下肖像、場景沒有留下圖像的，片中疊「人物與場景為想像重現」。
- 數學內容與名詞照課本（康軒），出處寫進核對表；對白是照步驟寫的，不寫成「他說過的名言」。
- 數學家的台詞只講他生前在做、可能知道的事；死後才有的事（墓誌銘、後人給的稱號、他的影響）交給旁白。（活人不知道自己哪年死，死人不會說話）
- 結尾留給學生的題目，答案不能從片中畫面直接讀出來：圖上畫了直線、表格列了規律時，問範圍外的值，讓學生要用方程式算；後製圖也不畫出指到答案的虛線。
- 原書、館藏掃描照原樣用，不加遮罩、不塗改；掃描上讀得到結尾題答案時改結尾題，不改圖。（遮罩會破壞原圖）
- 要畫圖就讓人物拿筆在紙上畫（H3 畫兩三條簡單直線沒問題）；畫的面看得清楚時照 `docs/rules/道具.md` 的做法（平視看不到畫面，或首幀就畫好、人指著講）。
